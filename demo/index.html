Struth Affordances new

The gap-fillers that turn stimulus_kanban from a generic Trello clone into something a real tradie can run a business on.

  1. 37 — Rich job-detail panel — tap-to-call / SMS / Navigate, photo carousel, materials with AUD total, activity timeline, action buttons
  2. 38 — Dispatcher board (unscheduled pool + day slots) — unscheduled-jobs rail + days×tradies grid; drag from pool to slot
  3. 39 — Bulk action toolbar — floating attachBulkActionToolbar() with primary / danger buttons
  4. 40 — Filter chips — Today / This week / Overdue / Mine / Unassigned / Urgent with live counts
  5. 41 — Time-in-column aging (stuck quote detector) — data-board-column-stuck-after-days-value; 5d ⚠ badge + board:cardStuck event
  6. 42 — Tag pills + click-to-filter — colored tags on cards; click a tag to filter the board
  7. 43 — Multi-tradie assignment (crew on a card) — overlapping avatars with gold-ring lead; tooltip role on hover
  8. 44 — Recurring-job badge (↻ annual / monthly / quarterly / weekly) — colour-coded cadence pill + next-due date; one-offs unbadged
  9. 45 — Customer-view swimlanes — one lane per customer to see their whole pipeline; toggle to suburb or assignee
  10. 46 — Card hover quick actions (call / SMS / map) — tel:/sms:/maps links revealed on :hover + :focus-within; always visible on touch
  11. 47 — Cross-board automation (Won quote → new job) — moving a quote into Won fires board:cardMoved; a host listener spawns the matching job on the other board with a green flash
  12. 48 — Card menu (⋯) — archive / duplicate / move-to-top — hover-revealed three-dot trigger with a fixed-position popover; Esc closes
  13. 49 — Photo carousel on card face — 2-up hero + 3-stack thumbnails; +N overflow badge; empty strip auto-hides
  14. 50 — Optimistic in-flight pulse — setCardPending / setCardError API; soft blue or red pulse animation while a save is in flight
