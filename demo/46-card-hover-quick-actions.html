46 — Card hover quick actions (call / SMS / map)

Hover any card to reveal a compact action strip in the top-right: 📞 tap-to-call, 💬 SMS, 📍 navigate. Each is a plain <a href="tel:…"> / sms: / Google Maps link — no JS required for the actual action. Visibility flips on :hover + :focus-within so keyboard users can tab into the actions and screen-reader users see them as proper links. On touch devices the strip is always visible (no hover state).

        // hover any card → quick actions appear. Clicking one fires the native tel:/sms:/maps URL.
