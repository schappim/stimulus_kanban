09 — Keyboard navigation

Click in the board, then use the arrow keys to navigate. Cmd + arrows actually moves the active card across columns / rows.

    1. Read RFC
    2. Write proposal

    1. Implement spec
    1. Publish post

Keys: ↑/↓ move within column · ←/→ move across columns · Cmd+arrows actually moves the card · Space toggles selection · Enter opens the editor · Cmd+A selects column.
